# Next-Files

## العربية
مدير ملفات لأندرويد لتنظيم الملفات وتنظيفها وضغطها وعرض الصور والفيديو وملفات PDF، مع خزنة ملفات ومشاركة عبر Wi‑Fi.

## English
An Android file manager for organizing and cleaning files, creating archives, viewing media and PDFs, protecting files in a vault, and sharing over Wi‑Fi.

## Build
يتم بناء APK من خلال GitHub Actions. مفاتيح التوقيع محفوظة في GitHub Secrets ولا توجد داخل المستودع.

The release APK is built through GitHub Actions. Signing credentials are stored in GitHub Secrets and are not included in the repository.
